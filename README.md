# داشبورد مالی متا

نسخهٔ وب گزارش مالی Power BI با صفحات **نمای کلی مالی**، **سود و زیان** و **بودجه و عملکرد**. دادهٔ منتشرشده ماهانه و تجمیعی است؛ جدول ریز اسناد حسابداری و شناسه‌های اشخاص/اسناد در این ریپو وجود ندارد. فایل PBIX نیز نباید به ریپو اضافه شود.

## پیش‌نمایش محلی

از پوشهٔ ریپو اجرا کنید:

```powershell
python -m http.server 4173
```

سپس `http://127.0.0.1:4173` را باز کنید.

## انتشار روی GitHub Pages

ریپو برای Pages آماده است. در تنظیمات ریپو، **Settings → Pages → Build and deployment → Deploy from a branch** را انتخاب کنید، سپس شاخهٔ `main` و پوشهٔ `/(root)` را تنظیم کنید. پس از ذخیره، GitHub Pages سایت را از فایل‌های همین شاخه منتشر می‌کند. دادهٔ نمونه از مدل PBIX استخراج شده و در `data/dashboard-data.json` قرار دارد.

## رفرش داده‌ها

مدل Power BI به SQL Server داخلیِ Sepidar وصل بوده است. GitHub Actions به شبکهٔ داخلی دسترسی ندارد؛ بنابراین رفرش واقعی باید روی کامپیوتری اجرا شود که به SQL Server دسترسی دارد. اسکریپت `python/refresh_from_sql.py` فقط تجمیع ماهانه را می‌خواند و هیچ ردیف سند حسابداری را صادر نمی‌کند.

1. Python، درایور Microsoft ODBC for SQL Server و بستهٔ `pyodbc` را نصب کنید.
2. فایل محلی `.env.local` را بسازید (در Git نادیده گرفته می‌شود):

   ```text
   SQL_SERVER=آدرس-سرور-قابل-دسترسی
   SQL_DATABASE=Sepidar04
   SQL_DRIVER=ODBC Driver 18 for SQL Server
   ```

   برای ورود ویندوزی، `SQL_USERNAME` و `SQL_PASSWORD` را ننویسید. در صورت استفاده از ورود SQL، این دو مقدار را فقط در `.env.local` قرار دهید و هرگز commit نکنید.

3. برای اجرای دستی رفرش و push:

   ```powershell
   .\refresh-and-publish.ps1
   ```

این فرمان به origin معتبر، `git config user.name` و `git config user.email` و ورود GitHub از قبل تنظیم‌شده روی کامپیوتر نیاز دارد. برای اجرای هرروزه ساعت ۳ صبح، می‌توان همین فایل را در Windows Task Scheduler زمان‌بندی کرد؛ کامپیوتر باید روشن، به شبکهٔ دیتابیس متصل و GitHub credential آن معتبر باشد. زمان‌بندی را تا وقتی این پیش‌نیازها تأیید نشده‌اند فعال نکنید.

## منطق محاسبه

- مقیاس نمایشی: میلیارد تومان (تقسیم ریال بر ۱۰٬۰۰۰٬۰۰۰٬۰۰۰).
- سود عملیاتی: فروش خالص − بهای تمام‌شده − هزینهٔ عملیاتی.
- سود قبل از مالیات: سود عملیاتی − هزینهٔ مالی + سایر درآمدها.
- دارایی‌ها، بدهی‌ها و حقوق صاحبان سهام از گردش حساب تا ماه انتخابی به‌صورت تجمعی محاسبه می‌شوند.
- سود عملکرد در مقایسهٔ بودجه مطابق مدل Power BI از درآمد واقعی منهای هزینهٔ واقعی به دست می‌آید؛ سایر درآمدها در این KPI منظور نمی‌شود.
- ماه‌های بدون عملکرد واقعی در نمودار و جدول خالی می‌مانند، نه صفر.

منطق SQL و شاخص‌های پایتون در پوشهٔ `python/` است. منبع دادهٔ این snapshot، فایل `meta.pbix` محلی بوده است؛ خود فایل منبع و اطلاعات اتصال در ریپو قرار نمی‌گیرند.
